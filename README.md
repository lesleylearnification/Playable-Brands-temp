## Structure
This repository follows the locked Game Collection Repository framework:
- persistent BACK control to the main portfolio
- fixed collection hero
- responsive normal-flow game grid
- three columns on desktop
- square approved game imagery
- complete card content within each grid cell
- 40px minimum row gap as additional games are added
